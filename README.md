# Tid, rytme, stillhet og stillstand

Lysbildene til Alexander Refsum Jensenius' innlegg på Symposium om tid i Det Norske Videnskaps-Akademi, 16. november 2026.

Se dem her: https://alexarje.github.io/dnva-tid-2026/

Tast S for talenotater, D for lys eller mørk modus og L for lyd på lysbildene med animasjon. Dekket er reveal.js. Kopien er laget med `tools/make_site.py` fra arbeidsmappen; rediger ikke her.
